# GenAI UX Workflow System

A structured AI-assisted UX workflow system built with Antigravity skills and custom orchestration rules.

## Project Overview

This project explores how multiple AI skills can work together through a structured workflow to support UX and product design.

## Repository Structure

- `docs/` Project documentation and case study
- `orchestration/` Global rules, skill selection and workflow logic
- `research/` Skill research, sources and comparisons
- `evaluations/` Workflow tests, observations and results

## Goals

- Organize specialized AI skills into a coherent workflow.
- Reduce conflicting instructions and inconsistent outputs.
- Establish clear rules for skill selection and orchestration.
- Evaluate the workflow through practical UX design tasks.
